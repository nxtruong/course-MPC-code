# Course MPC Code
Code examples and computational exercises for the graduate-level Model Predictive Control (MPC) course developed by Prof. Truong Nghiem.

## Repository organization

Each lecture directory contains the code and supporting material for the corresponding course topic. Examples may be provided in MATLAB, Python, or both.

Jupyter notebooks are included where appropriate for interactive exploration. They can be run locally or opened in Google Colab.

## Getting started

1. Clone or download this repository.
2. Navigate to the directory for the lecture of interest.
3. Review the files and instructions in that directory.
4. Run the MATLAB scripts or Python notebooks as indicated.

## Software requirements

- **MATLAB:** A compatible MATLAB installation; some examples may require additional toolboxes.
- **Python:** Python 3 and the packages listed or imported by the relevant example or notebook.
- **Jupyter:** Jupyter Notebook, JupyterLab, or Google Colab for interactive notebook execution.

## Notes

The examples are intended for educational use and accompany the course lectures. Refer to the individual lecture directories for problem-specific assumptions, dependencies, and instructions.
